# @turystack/nestjs-rate-limit

Distributed rate limiting for NestJS built on @turystack/nestjs-cache storage adapters.

## Installation

```bash
pnpm add @turystack/nestjs-rate-limit
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @nestjs/common @nestjs/core @turystack/nestjs-cache @turystack/nestjs-config reflect-metadata
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/nestjs-rate-limit**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
